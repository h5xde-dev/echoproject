# North Echo

<img src="public/logo.svg" width="72" alt="North Echo">

Кооперативный top-down шутер в духе **BulletEcho**: пули летят по-настоящему, свет и тени
решают всё, а рассвет наступает один раз. Сайт: **https://evntary.ru**.

Игра целиком работает в браузере. Одиночная игра и кооператив с друзьями идут
напрямую через P2P (WebRTC) и сервера не требуют. Рейтинговые бои ведёт игровой сервер:
вход через Яндекс ID, матчмейкинг, бой без ботов, рейтинг Эло в SQLite.

## Возможности

| | |
|---|---|
| **Обзор** | Как в Bullet Echo: видно только то, что в конусе взгляда и в паре метров вокруг, стены перекрывают обзор. Всё остальное погружено во тьму, враги вне обзора не рисуются (и на миникарте тоже), а их выстрелы оставляют красные маркеры. |
| **Солдаты** | Модели из пака ассетов с процедурной анимацией: шаги по скорости, руки держат оружие через IK, отдача, реакция на попадание, падение при смерти. |
| **Свет** | Фонарь игрока — настоящий `SpotLight` с shadow map: стены отбрасывают реальные тени. В темноте врагов почти не видно, выстрелы и взрывы освещают комнату. |
| **Пули** | Реальное время полёта и падение урона по дистанции, пули останавливаются стенами. Пушка летит мимо — можно уклониться. |
| **Физика** | Свойки-бочки взрываются цепной реакцией, ящики и столы толкаются, обломки отлетают. |
| **Режимы** | **Кооператив**: 6–8 процедурных комнат за бронированными дверями, стартовая комната без врагов. На аренах «Склад», «Двор», «Бункер», «Лес», «Офис», «Порт», «Завод», «Катакомбы», «Окопы», «Лабиринт» (боты добирают до 2–8 бойцов, таблица на Tab): **Deathmatch** — каждый сам за себя, 15 фрагов или 5 минут; **Гонка вооружений** — каждые 2 убийства дают следующее оружие (пистолет → ПП → дробовик → винтовка → снайперка), кто прошёл лестницу — победил; **Соревнование** — раунды до последнего выжившего, старт с пистолетом и $800, закупка на B в первые 15 с раунда, деньги за убийства и итог раунда, выжившие сохраняют снаряжение. |
| **Командные режимы** | **Командный бой** — синие против красных до 30 фрагов, без огня по своим, обзор союзника общий. **Захват флага** — унести чужой флаг к себе, пока свой на базе; упавший флаг возвращают касанием; три захвата — победа. **Закладка бомбы** — раунды: синие закладывают бомбу на A или B (зажать E, 3 с), красные обезвреживают (E, 5 с); бомба взрывается через 35 с; закупка и деньги как в «Соревновании», пять раундов — победа. **Волны** — кооп против волн охраны, которые растут и идут на шум и свет; погибшие возвращаются после волны. |
| **Фонарь** | Включён — обзор 24 м, но ИИ замечает издалека, а луч виден врагам сквозь темноту. Выключен — обзор 13 м, зато скрытно. Боты гасят фонарь, когда подкрадываются. |
| **Гранаты** | G — бросок к курсору по дуге, отскок от стен, взрыв через 2 с, стены защищают. Красный круг показывает зону поражения. Боты закидывают гранатами тех, кто прячется. |
| **Уровни** | Темы комнат — склад, офис, двор, бункер, ночной лес (густые кусты, стены — линии деревьев), поле с зигзагами окопов и мешками с песком: свой пол, свет, разметка и набор укрытий (машины, паллеты, бочки, электрощиты, покрышки, бетонные блоки). Колонны в больших комнатах. Неподвижные укрытия никогда не перекрывают проход. |
| **Тактика** | Лампы простреливаются: пуля игрока гасит свет, место становится тёмным и для ботов. Дымовая граната (Q, затем G) ставит облако на 14 с — сквозь него не видят ни игроки, ни боты, видны только трассеры. Светошумовая ослепляет всех, кто видит вспышку: дольше, если смотреть на неё. Коктейль Молотова разбивается там, где упал (или о стену), и пол горит 7 с: кто в огне — горит и после, бочки с топливом в пламени взрываются, огонь освещает место для ботов, а стены его не пропускают. В кустах (дворы, арена «Двор») не видно того, кто стоит, идёт шагом или сидит, — пока не выстрелит или не побежит. Окопы (комнаты-«поля» в коопе, арена «Окопы») замедляют на 15%; пригнувшегося в окопе не видно, а пули стрелка снаружи окопа издалека (больше 5 м) бьют того, кто в окопе, на 35% силы; охрана ждёт в окопах пригнувшись. FPV-дрон (X; у инженера один на жизнь, в магазине $900): солдат стоит, дрон летит над укрытиями 12 с. Управление как у настоящего квадрокоптера: мышь разворачивает нос (с ограниченной скоростью поворота), W/S — тангаж вперёд/назад, A/D — крен вбок относительно носа; дрон набирает скорость до ~60 км/ч, по инерции скользит и тормозит, наклоняется в сторону движения, а в стену на полной скорости разбивается; ЛКМ или X — подрыв (4,5 м, 120 урона), села батарея — тоже взрыв. Дрон жужжит (его слышат боты), камера и обзор — с дрона; его можно сбить (30 hp, боты стреляют по дрону рядом), а ранение пилота рвёт связь; сбитый, разбитый о стену или потерявший связь дрон падает и взрывается там, где упал. |
| **Бонусы** | Аптечка, броня (поглощает 60% урона), усиленный урон, скорость, скорострельность, ПНВ (10 с видно далеко без фонаря, но вспышка слепит сильнее). Враги иногда роняют бонусы; на аренах предметы возвращаются через 18 с. Оружие подбирается, просто пройдя по нему, и исчезает с карты; погибшие роняют своё оружие (30 с). Переключение — 1–5. |
| **Оружие** | Пистолет, ПП, дробовик, винтовка, снайперка — у каждого свои темп, разброс, отдача и урон. |
| **Враги** | ИИ с патрулированием, реакцией на шум, поиском по последней известной позиции, стрельбой очередями и перемещением в укрытии. В темноте реагируют хуже. |
| **Кооператив** | Два оператора на один объект. Хост authoritative: снимки состояния 20 Гц, предикт своего персонажа с откатом, интерполяция остальных. |

## Интерактив и механики

| | |
|---|---|
| **Объекты (E)** | Рубильник гасит или включает лампы в 13 м (простреленные остаются тёмными); ящик патронов — полный магазин и гранаты, откат 20 с; медпункт лечит, пока держите E (15 hp/с, запас 150 hp, восполняется); двери на аренах открываются и закрываются (держат пули и обзор, боты открывают сами). |
| **Сброс снаряжения** | Раз в минуту (в коопе — 90 с, в «Волнах» — 75 с) на парашюте падает ящик с красным дымом, место видно на миникарте. Зажать E на 2 с — топовый ствол и два бонуса; урон сбивает вскрытие. |
| **Серии убийств** | 3 подряд — радар на 8 с, 5 подряд (и каждые следующие 5) — миномётный удар: T ставит три мины по курсору, через 2 с свиста они падают. Смерть обнуляет серию. |
| **Проволока, ракеты, мины** | Колючая проволока замедляет вдвое и ранит, пули её пролетают; режется ножом или зажатой E. Осветительная ракета (граната, Q) 12 с освещает 9 м — там не спрятаться ни в кусте, ни в окопе, ни под маскировкой. Мины инженера (N, две на жизнь, $300 в магазине): взрываются под врагом, врагам видны только вблизи, расстреливаются. |
| **Бонусы** | Кроме аптечки, брони, урона, скорости, темпа и ПНВ: боеприпасы, регенерация (вне перестрелки), сверхщит, маскировка, радар. На каждой арене есть новые бонусы, в коопе — до двух на комнату; убитые на аренах иногда роняют бонус. |
| **«Лабиринт»** | Арена-лабиринт из окопов: тыловая и передняя линии зигзагом, ходы сообщения, тупики, два блиндажа (дверь, медпункт, патроны, рубильник), пулемётные гнёзда и ничейная земля с воронками и проволокой. Окопы теперь выглядят вырытыми: дощатые стенки, столбы, мешки с песком по брустверу. |

**Боты в сетевой комнате.** Переключатель «Боты в сетевой комнате» в меню, под числом бойцов
на арене. Если боты включены, они появляются, только когда в комнате двое игроков или
больше: хост, который ждёт друзей, не попадёт в бой с ботами в одиночку. Когда остаётся
один игрок, боты уходят. Если переключатель выключен, в комнате играют только люди. Выбор
запоминается. В одиночной игре боты есть всегда, в рейтинговом бою их нет никогда.

В меню есть **«Справка»** (и в паузе): классы, режимы, оружие с характеристиками, бонусы, объекты и все клавиши. Под кнопками классов — карточка выбранного класса.

## Интерфейс

- **Лобби.** «Создать комнату» открывает разминку: можно бегать и стрелять, пока подключаются друзья. Они жмут «Готов», хост — «Начать матч», и все переходят в свежий матч.
- **Настройки** в меню паузы (Esc): громкость, графика (низкая — без теней и с пониженной плотностью пикселей), тряска камеры, счётчик FPS и пинга. Запоминаются в браузере.
- **После смерти** камера пару секунд показывает убийцу, затем следует за живым союзником.
- **Метки** (Z или колёсико мыши) видят союзники — на экране и на миникарте.
- **Миникарта** показывает шум невидимых врагов: выстрелы и шаги.

## Классы и прогресс

- **Класс** выбирается в меню: штурмовик (+1 осколочная, быстрая перезарядка), разведчик (тихие шаги, быстрый присед, ПНВ на старте), медик (поднимает вдвое быстрее, лечит союзников рядом), инженер (переносной щит на V, FPV-дрон на X).
- **Оружие:** к пяти стволам добавились пулемёт, пистолет с глушителем (не оставляет маркера), нож (8): удар в спину убивает сразу, спереди — 80 урона, с ножом в руке бегаешь быстрее, — и огнемёт (9): бьёт на 8 м, поджигает, не берёт дальше.
- **Прогресс:** за матч начисляется опыт — убийства, цели, поднятые союзники, комнаты и волны, победа. Уровни открывают цвета кольца бойца, их видят все. Хранится в браузере на этом устройстве.
- **Кооператив:** раненого можно поднять (зажать E); если стоять некому — поражение. Враги бывают тяжёлые, снайперы (видна лазерная линия) и разведчики. Комнаты задают задачи: взломать терминал или обезвредить заряд. В «Волнах» между волнами работает магазин, каждая пятая — с боссом.
- **Боты** — лёгкие, обычные или тяжёлые (меню).

## Ассеты

Модели, текстуры и звуки лежат в `public/assets/` (~2.7 МБ) и собираются из
библиотеки ассетов frontline скриптом:

```bash
FRONTLINE_ASSETS=~/frontline/assets npm run assets
```

Скрипт упрощает сетки, пережимает текстуры в WebP и сжимает геометрию meshopt.
Результат коммитится, поэтому деплой от frontline не зависит. Проверить, как
легли модели: `/test/models.html`, анимацию — `/test/anim.html` (на dev-сервере).

## Сайт и игровой сервер

| Адрес | Что там |
|---|---|
| `/` | посадочная страница для поиска: описание, режимы, FAQ, кнопка «Играть» |
| `/play` | сама игра |
| `/rating` | таблица рейтинга (сервер вставляет её в HTML, чтобы её видели поисковики) |
| `/auth/yandex`, `/callback` | вход через Яндекс ID (OAuth 2.0, код авторизации) |
| `/api/me`, `/api/leaderboard`, `/api/matches` | профиль, таблица, история боёв |
| `/ws` | рейтинговые бои |

**Рейтинговый бой.** Кнопка в меню ставит игрока в очередь. Бой начинается сразу, когда
набирается 6 игроков, или через 20 с после того, как в очереди появились двое. Сервер
сам ведёт ту же симуляцию, что и браузеры (`src/game/sim.ts`), это deathmatch на
случайной арене и **без ботов**.

Транспорт устроен так:
- WebSocket (TCP) несёт всё, что обязано дойти: приветствие с картой, события боя и
  ввод с разовыми действиями (граната, покупка);
- WebRTC data channel работает без порядка и без повторов, то есть как UDP. По нему
  идут снапшоты (20 в секунду), обычный ввод и пинги;
- если UDP закрыт, всё идёт по WebSocket.

Клиент интерполирует чужих бойцов со сдвигом в 110 мс, а своего предсказывает и
сверяет со снапшотами. Опоздавшие снапшоты отбрасываются.

Выбывший игрок может вернуться в течение 30 с. Если он не вернулся, он занимает
последнее место. Если в бою остался один игрок, через 20 с бой засчитывается.

**Рейтинг** — многопользовательский Эло. Каждый сравнивается с каждым по месту в бою,
K = 32 делится на число соперников. Старт — 1000. Всё хранится в SQLite: пользователи,
сессии, бои, строки игроков по боям (`server/db.ts`).

## Деплой (evntary.ru)

Сервер 157.228.137.18, Ubuntu 24.04, nginx и certbot.

**Разовая настройка.** Скрипт `deploy/setup.sh` идемпотентен:

```bash
YANDEX_CLIENT_ID=… YANDEX_CLIENT_SECRET=… bash /var/www/northecho/deploy/setup.sh
```

Он делает следующее:
- создаёт пользователя `northecho` и клонирует репозиторий в `/var/www/northecho`;
- пишет секреты в `/etc/northecho/env` (права 640, вне репозитория);
- получает сертификат Let's Encrypt для evntary.ru и www через webroot. Продление
  выполняет `certbot.timer`, после него nginx перезагружается;
- ставит `deploy/nginx.conf`: статика из `dist`, прокси на сервер `127.0.0.1:8090`,
  редирект с http и с www;
- ставит systemd-юниты `northecho` (игровой сервер, база в `/var/lib/northecho/north.db`)
  и `northecho-deploy.timer`.

**Автодеплой.** Раз в минуту `deploy/deploy.sh` проверяет `main` на GitHub. Если там
новый коммит, скрипт:
1. подтягивает его;
2. запускает `npm ci`, если менялся lock-файл;
3. проверяет типы;
4. собирает сайт рядом с работающим и подменяет его одним `mv`;
5. перезапускает игровой сервер, только если изменился его код. Идущие рейтинговые бои
   не рвутся из-за правок вёрстки.

Достаточно сделать push в `main`. Логи:

```bash
journalctl -u northecho-deploy -f   # деплой
journalctl -u northecho -f          # игровой сервер
```

UDP-порты WebRTC — 40000–40199. Они должны быть открыты во входящих, если у хостинга
есть свой файрвол.

## Как устроена кооперативная игра

1. Первый игрок жмёт **«Создать комнату»** — хост получает пятисимвольный код.
2. Второй вводит код в поле «Код комнаты» и жмёт **«Войти»**.
3. Оба браузера соединяются напрямую через WebRTC (сигнализация — публичный
   сервер PeerJS, данные идут напрямую, не через сервер).

**Хост authoritative.** Хост держит полную симуляцию, клиент отправляет только
ввод (движение, прицел, кнопки) 60 раз в секунду. Хост рассылает снимки
состояния 20 раз в секунду; клиент:

- предсказывает движение своего персонажа и при получении снимка переигрывает
  неподтверждённый ввод, сверяясь с хостом;
- интерполирует остальных сущностей с задержкой ~110 мс;
- воспроизводит трассеры локально по событию выстрела, а id пуль сверяет со
  снимками, чтобы мгновенно показать выстрел, не дожидаясь снимка.

**Компенсация лага.** Клиент сообщает хосту свой пинг в каждом пакете ввода, и
хост «догоняет» его пулю на половину пинга (не больше 150 мс), прогоняя её
обычными тиками — стены и тела на пути учитываются. Худший пинг клиентов хост
видит у себя в HUD.

**Обрыв связи.** Если канал до хоста оборвался, клиент трижды пробует войти в
ту же комнату; не вышло — матч завершается с экраном «СВЯЗЬ ПОТЕРЯНА». Если
хост теряет сигнальный сервер, уже подключённые игроки продолжают играть, а
комната перерегистрируется, чтобы новые могли войти.

### Если соединение не устанавливается

По умолчанию PeerJS даёт публичные STUN и TURN. Свои серверы надёжнее; их
можно задать переменными окружения сборки (в Vercel — Settings → Environment
Variables):

| Переменная | Пример |
|---|---|
| `VITE_PEER_SIGNAL` | `peer.example.com:443` |
| `VITE_ICE_SERVERS` | `[{"urls":"turn:turn.example.com:3478","username":"user","credential":"pass"}]` |

Параметры URL ниже перекрывают эти переменные — удобно для проверки.

Прямое соединение может не пробить NAT. В этом случае помогает TURN-релей:

```
https://ваш-домен/?ice=[{"urls":"turn:turn.example.com:3478","username":"user","credential":"pass"}]
```

Также можно указать свой PeerServer (он же обычно даёт TURN):

```
https://ваш-домен/?signal=peer.example.com:443
```

### Про VPN

TUN-VPN (Clash/Surge и подобные) подменяют локальные адреса на диапазон
`198.18.0.0/15`, и Chrome предлагает его как ICE-кандидат. Между двумя
пирами одного компьютера такой трафик может не проходить — это особенность
окружения, а не игры. Решения: отключить VPN на время сессии, подключиться из
разных сетей или использовать TURN.

## Структура

```
src/
  core/      математика, seeded RNG, ввод, WebAudio-синтез (без аудио-файлов)
  game/      детерминированная симуляция: физика, пули, ИИ, генерация уровней
  render/    Three.js: сцена, свет с тенями, процедурные текстуры, частицы
  net/       PeerJS-транспорт, связь с сервером (WebSocket + UDP-канал), протокол, снапшоты
  ui/        HUD, миникарта, меню, аккаунт
server/      игровой сервер: Яндекс ID, SQLite, матчмейкинг, рейтинговые бои, рейтинг Эло
deploy/      nginx, systemd, автодеплой
test/        интеграционные тесты: сетевой код (loopback), арены, рейтинговый сервер
```

Физика и правила боя живут в плоскости XZ — как 2D, но в 3D-сцене. Это даёт
детерминированную симуляцию (важно для синхронизации) и дешёвые расчёты.

## Тесты

```bash
npm run typecheck    # tsc --noEmit
npm run test:netcode # интеграционный тест: два игровых инстанса, host-authoritative,
                     # движение по сети, репликация пуль, отсутствие ошибок в консоли
npm run test:arenas  # арены и режимы на ботах, походка, шум шагов, разброс
npm run test:server  # рейтинговый бой целиком: вход, очередь, бой без ботов по UDP,
                     # рейтинг после ухода соперника (нужен запущенный сервер, см. файл)
```

Тесты ходят на запущенный `npm run dev` (порт 5173).

Профиль кадров: `node tools/perf.mjs [арена] [режим] [секунды]` (`PERF_CPU=4` замедляет
процессор вчетверо, как на слабом ноутбуке). Скрипт играет матч с ботами, вызывает сброс,
ракету, мину, миномёт, огонь, дрон и бонусы. Он выводит медиану и хвосты времени кадра,
время JS, самые дорогие методы и шейдеры, скомпилированные посреди боя (их быть не должно:
всё, что появляется в бою, прогревается в `Renderer.warmup`).

Тест поднимает две полноценные игры рядом и соединяет их через
in-memory транспорт (`test/loopback.ts`), поэтому проверяет весь сетевой код
без участия WebRTC.
